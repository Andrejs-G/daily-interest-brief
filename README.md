# Daily Interest Brief — PWA для iPhone

Лёгкая новостная сводка на HTML, CSS и JavaScript без внешних фреймворков, библиотек, шрифтов и сборки. Пять карточек, тёмная тема, фильтры по категориям, кнопка **Refresh**, установка на экран iPhone и чтение сохранённого выпуска без интернета.

**Комплект содержит вымышленные демо-новости.** Они показывают формат приложения и не являются реальной сводкой за указанную дату. Для настоящего выпуска замените `news.json` проверенными материалами и установите `demo: false`.

`feed.js` содержит общую проверку формата сводки для интерфейса и service worker. `.nojekyll` позволяет GitHub Pages публиковать файлы как готовый статический сайт.

## Запуск на компьютере

1. Распакуйте архив и откройте терминал в папке, где находится `index.html`.
2. Запустите встроенный сервер Python 3:

   ```bash
   python3 -m http.server 8000 --bind 127.0.0.1
   ```

3. Откройте [http://localhost:8000](http://localhost:8000) в браузере.
4. Для остановки сервера нажмите `Ctrl+C` в терминале.

Открытие `index.html` двойным щелчком через `file://` не подходит: загрузка JSON и регистрация service worker требуют веб-сервера. На компьютере `http://localhost` допускается для разработки; для доступа с iPhone используйте опубликованный **HTTPS-адрес**. Обычный адрес компьютера в локальной сети по HTTP не даст полноценный офлайн-режим. [Требования Service Worker API](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API).

## Установка на iPhone

1. Опубликуйте папку одним из способов ниже.
2. Откройте её HTTPS-адрес в **Safari** и дождитесь загрузки карточек.
3. Нажмите **Поделиться / Share**. В зависимости от расположения панели Safari эта команда может находиться внутри меню страницы.
4. Выберите **На экран «Домой» / Add to Home Screen**. Если пункта нет, найдите его через **Изменить действия / Edit Actions**.
5. Если показан переключатель **Open as Web App**, включите его; нажмите **Добавить / Add**.
6. Откройте новую иконку и один раз загрузите сводку с интернетом. Затем её сохранённая версия будет доступна офлайн.

Названия пунктов зависят от языка и версии iOS. [Инструкция Apple](https://support.apple.com/guide/iphone/iphea86e5236/ios).

## Публикация через GitHub Pages

1. Создайте репозиторий, например `daily-interest-brief`.
2. Добавьте **содержимое папки** в корень ветки `main`: `index.html` должен находиться сразу в корне репозитория.
3. Откройте **Settings → Pages → Build and deployment**.
4. Выберите **Source: Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**.
5. Дождитесь успешной публикации. Используйте адрес, показанный в Pages; для обычного репозитория проекта он имеет вид `https://USERNAME.github.io/daily-interest-brief/`.

При следующем выпуске замените `news.json` и сохраните изменение в той же ветке. После завершения публикации нажмите **Refresh** в приложении. Если папка размещена в `/docs`, выберите `/docs` как источник публикации. [Настройка источника GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Публикация через Cloudflare Pages

### Самый простой способ: Direct Upload

1. В Cloudflare откройте **Workers & Pages → Create application → Get started → Drag and drop your files**. В некоторых вариантах интерфейса сначала выбирается вкладка **Pages**.
2. Задайте имя проекта.
3. Перетащите распакованную папку с приложением. Убедитесь, что в корне загружаемых файлов находится `index.html`, а не ещё одна внешняя папка. Сборка не нужна.
4. Нажмите **Deploy site / Save and Deploy** и откройте выданный адрес `https://PROJECT.pages.dev`.
5. Для обновления выберите **Create a new deployment → Production** и загрузите обновлённую папку целиком.

Cloudflare также принимает ZIP с файлами сайта. Если архив содержит внешнюю папку `daily-interest-brief`, удобнее распаковать его и загрузить эту папку. Проект Direct Upload нельзя впоследствии переключить на Git integration — для неё создаётся новый проект. [Direct Upload: официальная инструкция](https://developers.cloudflare.com/pages/get-started/direct-upload/).

### Вариант: обновление из Git

В **Workers & Pages → Create application → Pages → Import an existing Git repository** подключите репозиторий. Выберите ветку `main`, пресет **None**, команду сборки `exit 0` и каталог результата `.` при размещении файлов в корне. Если приложение лежит в отдельной папке, укажите её как корневой каталог проекта. После публикации изменения выбранной ветки будут автоматически развёртываться. [Публикация статического HTML в Cloudflare Pages](https://developers.cloudflare.com/pages/framework-guides/deploy-anything/).

## Как обновлять сводку

Редактируйте `news.json` в UTF-8, сохраняя корректный JSON: двойные кавычки, без комментариев и без запятой после последнего элемента. Готовый файл из комплекта служит полным примером.

| Поле | Формат и назначение |
| --- | --- |
| `schemaVersion` | Обязательное число `1`, версия формата сводки |
| `demo` | `true` для демонстрации; `false` для реального проверенного выпуска |
| `date` | Дата выпуска `YYYY-MM-DD`, например `2026-11-09` |
| `updatedAt` | Момент подготовки с часовым поясом, например `2026-11-09T08:35:00+02:00` или `2026-11-09T06:35:00Z` |
| `headline` | Необязательная короткая строка о главной теме выпуска |
| `items` | Массив ровно из **5** новостей в порядке важности |
| `items[].id` | Уникальная непустая строка для каждой новости |
| `items[].categories` | Массив из одной или нескольких допустимых категорий |
| `items[].title` | Заголовок |
| `items[].summary` | Краткое содержание |
| `items[].impact` | Почему новость имеет значение для читателя |
| `items[].source` | Необязательный объект `{"name":"Название источника","url":"https://…"}` либо `null`; ссылка должна вести на материал |

Допустимые категории: **Macro**, **Pure Alpha**, **Geopolitics**, **Shipping**, **EV/Porsche**, **AI**, **NHL**. Регистр и написание должны совпадать. Новость с несколькими категориями появляется в каждом соответствующем фильтре; в общей ленте она остаётся одной карточкой. Фильтр может быть пустым, если в выпуске нет материалов этой категории. Изображения не обязательны и не используются: весь интерфейс сохраняется офлайн без внешних ресурсов.

Время `updatedAt` показывается в часовом поясе **Europe/Riga** с учётом перехода на летнее время: указанный в JSON момент переводится во время Риги. Дата выпуска берётся отдельно из `date` и не сдвигается из-за часового пояса устройства.

После сохранения файла опубликуйте новую версию и нажмите **Refresh**. Приложение запрашивает `news.json` при открытии и по этой кнопке. Если новый файл некорректен или недоступен, приложение сохраняет возможность читать последнюю корректную сводку и показывает состояние загрузки.

**Автоматическая доставка из ChatGPT не подключена.** Этот MVP читает опубликованный JSON; он не создаёт новости, не запускает ежедневные задания и не содержит сервер, API-ключи или push-уведомления. Для ежедневной автоматизации отдельный процесс должен готовить и публиковать новый `news.json`.

## Офлайн и обновление приложения

Service worker сохраняет HTML, CSS, JavaScript, манифест, иконки и сводку. Для `news.json` сначала используется сеть; при её недоступности возвращается сохранённая копия с техническим заголовком `X-Brief-Cache: offline`. Дополнительно приложение хранит последнюю проверенную сводку в локальном хранилище браузера.

Кэш изолирован по адресу установки: разные проекты на одном домене не должны очищать данные друг друга. Для изменения только новостей достаточно заменить JSON. При выпуске новых HTML/CSS/JS или иконок увеличьте `CACHE_VERSION` в `service-worker.js`, опубликуйте файлы вместе и повторно откройте приложение с интернетом.

Офлайн-режим требует хотя бы одного успешного посещения и завершённой установки service worker. Он сохраняет последний доступный выпуск, а не архив всех дней. Ссылки на внешние источники требуют интернета. Если iOS очистит данные сайта, пользователь удалит их вручную или браузер запретит хранилище, потребуется снова загрузить приложение онлайн.

## Короткая проверка после публикации

1. Откройте сайт: отображаются пять карточек и отметка демонстрационного выпуска.
2. Переключите все категории; вернитесь к общей ленте.
3. Измените заголовок одной новости в `news.json`, опубликуйте файл и нажмите **Refresh**: должен появиться новый текст.
4. После успешной загрузки отключите интернет и повторно откройте приложение: сохранённый выпуск должен оставаться доступным с отметкой состояния.
5. Проверьте установку через Safari на самом iPhone. Мобильный предпросмотр на компьютере не заменяет проверку установки на устройстве.
